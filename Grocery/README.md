# 🛒 Grocery– Grocery Store Website

A simple and responsive **Grocery Store Website UI** created using **HTML and CSS**. This project was developed as a frontend practice project to improve skills in webpage structure, styling, layouts, navigation, and responsive design.

## 📌 Project Overview

**Grocerycloned** is a grocery store landing page that presents fresh and organic products, product categories, customer reviews, blogs, and contact information.

The website includes a clean navigation bar and multiple sections that can be accessed through smooth scrolling.

## ✨ Features

* 🏠 Home section with grocery store introduction
* ⭐ Features section

  * Fresh and Organic Products
  * Free Delivery
  * Easy Payments
* 🛍️ Products section

  * Fresh Oranges
  * Fresh Onions
  * Fresh Meat
  * Fresh Cabbage
  * Fresh Potato
  * Fresh Avocado
* 📦 Product Categories

  * Vegetables
  * Fresh Fruits
  * Dairy Products
  * Fresh Meat
  * Fast Food
  * Sea Food
* 👥 Customer Reviews
* 📰 Blog section
* 📞 Contact Information
* 🔗 Social Media Icons
* 🧭 Navigation menu with smooth scrolling
* 🎨 Custom styling using CSS
* 🖼️ Product and category images

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **Google Fonts** – Poppins, Open Sans, Raleway and Rochester
* **Font Awesome** – Social media and contact icons
* **Material Icons** – Location icon

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Grocerycloned.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Grocerycloned
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use **Visual Studio Code with Live Server** to run the project locally.
