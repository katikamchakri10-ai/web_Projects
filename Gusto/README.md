# 🍽️ Gusto Cloned Website

A frontend practice project that recreates the design and layout of a restaurant website using **HTML and CSS**. The project focuses on creating a clean restaurant landing page with navigation, food specials, restaurant information, chef section, reservations, contact form, and social media links.

## 📌 Project Overview

**Gusto Cloned Website** is a static restaurant website inspired by the Gusto restaurant template design.

The website contains multiple sections connected through navigation links, allowing users to smoothly move between different parts of the page.

* 🏠 Restaurant hero section

## 🌐 Website Sections

### 🍽️ Hero Section

The hero section introduces the restaurant with the **Gusto** heading and reservation phone number.

```text
Gusto

Reservation: (887) 654-3210
```

### ⭐ Our Specials

Displays three restaurant specials with:

* Dish title
* Food image
* Description

### 📖 Our Story

Provides information about the restaurant using a two-column layout containing an image and restaurant description.

### 🖼️ Gallery

A four-image gallery showcasing restaurant/food images.

### 👨‍🍳 Meet Our Chef

Introduces the restaurant's chef with descriptive content and a chef image.

### 📞 Reservations & Contact

The contact section includes:

* Send Message button

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Gusto-Cloned-Website.git
```

### 2. Open the Project

```bash
cd Gusto-Cloned-Website
```

### 3. Run the Website

Open `index.html` in your browser.

You can also open the project using **Visual Studio Code** and run it with the **Live Server** extension.
